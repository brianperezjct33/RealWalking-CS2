# Real Walking — 研发与调试历史

## 一、步行系统：早期研究至 G1.9

| 版本／阶段 | 开发与调试记录 |
| --- | --- |
| **v0.2.0–v0.2.5** | 研究游戏的 Net、Lane 与 ECS 接口。前期遇到程序集引用和 API 命名问题；至 v0.2.5，已在游戏中读取到真实的 `PedestrianLane` 和 `Curve` 数据。 |
| **v0.2.6–v0.2.7** | 增加附近行人路径、曲线坡度和采样位置的扫描；改为手动触发扫描。已读取到行人曲线，但测试中未找到目标坡道。 |
| **G0.1–G0.2** | 尝试单独编译 FPC 代码，修复 `GetValueOrDefault` 兼容性错误。G0.2 收到编译通过的反馈。 |
| **G1–G1.1** | 从 FPC 读取第一人称相机位置，搜索附近的行人车道。发现只按邻近车道查询，无法稳定识别所在的人行道。 |
| **G1.3（v0.3.4–v0.3.7）** | 增加通过道路 Net 所属对象查找 `SubLane` 的方法，并读取 `Navigation Area` 三角形；完善楼层高度判断和扫描日志。最终记录了 39 次完整扫描。 |
| **G1.4** | 在第一人称画面中显示行人 Net 路径与 Navigation Area 三角形，便于观察天桥、地铁楼梯和不同高度的导航面。修复相关 Unity ECS 编译错误后，游戏内可视化得到确认。 |
| **G1.5** | 首次通过 FPC `HeightOffset` 实现自动贴合步行表面的第一人称移动，开始区分导航、地形与自由飞行模式。天桥通行得到确认，但路径宽度、码头高度和性能仍需改进。 |
| **G1.5 Fix1** | 将调试可视化与实际通行数据缓存分离，避免画线数量限制影响导航候选；默认隐藏小型调试雷达。 |
| **G1.6** | 加入步行边界约束与安全位置恢复，防止玩家离开道路时自动进入自由飞行。测试发现限制过严，斜向贴边行走容易被卡住。 |
| **G1.7** | 加入沿边界滑动；普通人行道设置最小宽度规则，扩大部分步行道路的可走范围，并缓存附近路径数据。测试反馈卡顿减轻，但地铁楼梯底端仍无法衔接。 |
| **G1.8** | 调整宽型步行道路系数至 2.25，收紧站台靠近铁轨一侧的边界。测试发现部分楼梯底部的 Navigation Area 三角形悬空；增加的高度平滑还会造成快速下楼时视角滞后。 |
| **G1.9（v0.9.0）** | 为悬空楼梯下端加入受约束的虚拟坡脚连接；取消最终高度平滑和垂直速度限制，改进码头高度补偿。**实机确认：悬空楼梯接缝、快速上下楼、码头行走三个重点场景通过。** |
| **G1.9.1 性能诊断／早期 RC3** | 针对 3 倍模拟速度下导航模式卡顿，增加帧间隔与 ECS 等待计时。一次有效记录中，导航控制器平均约 0.165 ms，ECS 等待峰值约 0.008 ms；出现过较长帧间隔，但未确定其原因。未因此重写已稳定的步行算法。 |

## 二、交通交互实验及架构转向

| 阶段 | 开发与调试记录 |
| --- | --- |
| **G2.0** | 勘测 `HumanCurrentLane`、`LaneObject`、`LaneOverlap` 等 ECS 结构，并确认可识别原版人行横道标志。 |
| **早期 RC4–RC4.1** | 制作只读交通采样工具，分别采集普通人行道、有无信号灯的斑马线和不同高度道路的数据。修复 ECS `Time` API 编译错误；采集到 80 个快照和 413 条生物实体观察记录。 |
| **G2.1／早期 RC5** | 创建临时隐形行人代理，尝试登记到人行横道并触发车辆让行。日志记录了 6 次创建与 6 次清理。游戏中观察到车辆减速，但汽车仍会穿过玩家，未能实现可靠的停车等待。 |
| **G2 分支终止** | 决定停止隐形行人代理与车辆让行的开发，不将实验性 ECS 代理纳入后续独立版。开发重点改为第一人称乘坐公共交通。 |
| **早期 RC6–RC6.1** | 加入 **E 键上车／下车** 的初步交互，利用外部 FPC 跟随交通工具。实测公交与船舶可乘坐；多节列车及地铁仍有车厢识别和相机位置问题。 |
| **早期 RC7–RC7.1** | 继续调整列车车头识别、驾驶室位置及安全下车逻辑。相关问题尚未全部解决，随后转向整合 FPC 的独立版架构。 |
| **官方工程迁移** | 将已实现的步行系统迁入游戏官方 C# Mod 工程，修复 Unity ECS 源码生成器对非 `partial` 系统类造成的重复声明错误。编译与游戏内运行均获得成功反馈。 |

## 三、独立版整合：S1 系列

| 版本 | 开发与调试记录 |
| --- | --- |
| **S1** | 开始将所需 FPC 相机功能整合进 Real Walking，改为不依赖外部 FPC 的独立模组。首次整合编译失败。 |
| **S1.1** | 修复 .NET Framework 下 `Dictionary.GetValueOrDefault` 的兼容性编译错误。 |
| **S1.2** | 处理相机控制器尚未初始化时可能发生的 `NullReferenceException`，加入安全跳过与延迟恢复逻辑。 |
| **S1.3** | 精简整合后的相机代码，移除不再需要的画中画、随机跟随和旧版大型 UI 等功能，保留步行与乘车所需部分。 |
| **S1.4** | 重新实现独立的公共交通站点条 UI。游戏内确认站点条可用，但站名与显示尺寸存在问题。 |
| **S1.5–S1.5.1** | 加入实际站名读取、列车驾驶室位置计算及铁路站台下车的初步实现；修复 `RWStopNames.cs` 中缺失命名空间引起的编译错误。 |
| **S1.6** | 针对列车前后方向可能识别反的问题，增加首尾车厢方向判断；调整站点线路示意和站台检查。 |
| **S1.7–S1.7.1** | 修复站序 UI 绘制不连续的问题，调整地下车站候选识别；同时处理 `Game.Pathfind.Position` 和 IMGUI 事件类型相关编译错误。 |
| **S1.7.2** | 地铁站缺少有效站点位置标记时，改为在停车位置附近搜索同层可行走区域作为下车落点。**游戏内反馈地铁下车已可用。** |
| **S1.7.3** | 将地铁的几何落点搜索方法扩展至火车下车。 |
| **S1.7.4** | 为摆渡船及大型客轮增加码头附近的专用下车落点搜索。 |
| **S1.7.5** | 实测发现船舶下车可能落到接近水面的行人路径；随后加强落点高于水面及可行走几何的检查。 |
| **S1.7.6** | 处理进入步行时残留的建筑选中高亮；从站点条 UI 中移除“站序示意”。随后的 Windows 编译问题通过补充引用和调整 UI 调用方式处理。 |

## 四、独立版候选版本：RC1–RC27

以下 RC 编号从独立版开始重新计算，与第二节的早期交通实验版不同。

| 版本 | 开发与调试记录 |
| --- | --- |
| **RC1** | 检查与外部 FPC 同时加载时的潜在冲突；调整独立版的本地化读取实现。 |
| **RC2** | 不再依据中文名称判断交通工具类型；加入多语言文本、英文回退及本地化检查。 |
| **RC3** | 尝试解决退出第一人称后相机返回原位置的问题。该方案后来在 RC6 再次调整。 |
| **RC4** | 取消 WASD 自动脱离载具跟随，明确 E 键下车和自由飞行切换的控制方式。 |
| **RC5／热修复** | 加入车辆完全停止后才能上车的判断，并在按 E 时重新检查；随后修复 `InterpolatedTransform` 相关的编译兼容问题。 |
| **RC6** | 实测发现退出第一人称后相机可能突然飞到远处；改为从当前视点交接相机位置，并清除载具跟随状态。 |
| **RC7** | 调整船舶下车时的站点标记缓存，避免几何扫描与实际按 E 时使用不同标记。 |
| **RC8** | 为大型客轮单独扩大可上车候选与码头落点搜索范围。 |
| **RC9** | 针对船体上下浮动导致上船提示闪烁，改用水平位移和朝向判断大型船舶是否停稳。 |
| **RC10** | 诊断出某高架客轮码头的下车高度条件互相冲突；调整码头高度参考和允许的垂直范围。 |
| **RC11** | 修复下船后再次进入第一人称时可能重新跟随旧船的问题，清除残留的相机／载具跟随引用。 |
| **RC12** | 将 RC9 的船舶停稳和提示防闪烁机制扩展到摆渡船。 |
| **RC13** | 改为直接以世界坐标中的可走表面高度计算视角眼高，解决地形或海平面高度干扰楼梯、高架步行道和码头的问题。 |
| **RC14** | 尝试通过切换前的相机状态与射线查询确定 Alt+F 进入步行时的落点。 |
| **RC15** | 因射线选点不便，尝试在屏幕附近搜索可行走位置，并加强滨水区域筛选。 |
| **RC16** | 纠正部分行人路径被过度加宽的问题，将双倍宽度特例限制到原版 `Pedestrian Street`。 |
| **RC17** | 调整进入步行时的路径扫描范围，减少有效候选被过早截断的问题。 |
| **RC18** | 放弃以画面瞄准位置为中心的选点方式，改为寻找**距离进入前相机三维位置最近的安全可行走点**。这一方案获得游戏内测试通过的反馈。 |
| **RC19** | 将高频详细诊断日志改为按需开启，减少正常游玩时的日志输出；步行与乘车算法未变。 |
| **RC20** | 修复较长的英文站名／线路名被截断的问题，调整站点条文本布局与显示方式。 |
| **RC21** | 精简模式和快捷键：使用 J 切换 Navigation／Free，使用 V 管理调试叠加层；移除旧 Terrain 模式及冗余键位。 |
| **RC22** | 修复自由飞行经过海岸或地形变化时高度异常；限制公交／有轨电车必须停稳且存在安全落点才能下车。 |
| **RC23** | 拆分交通扫描、载具跟随、下车落点、UI 与导航可视化代码，减少单文件承担过多职责的情况。 |
| **RC24** | 继续拆分步行控制、Net／Area 几何查询、铁路站台与码头落点计算，保持核心算法和阈值不变。 |
| **RC25／BuildFix1** | 调整 `src/` 目录结构、拆分初始化逻辑并删除无用辅助代码。清理后出现 `CS0246`：删除旧文件导致残留 `using` 无效；随后修复编译问题。 |
| **RC26** | 清理已废弃的实验探针、旧性能统计和日志工具，保留当前需要的调试界面与错误记录。 |
| **RC27** | 最后整理未使用的辅助函数、旧选中／随机跟随接口及失效本地化键；保留现有步行、乘车和下车逻辑。 |
