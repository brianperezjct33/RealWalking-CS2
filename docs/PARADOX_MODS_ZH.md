# Real Walking — Standalone｜城市漫步·独立版

## 简短介绍
在《城市：天际线 II》中真正走进自己的城市：自由步行、上下楼梯、探索车站与滨水空间，并乘坐公共交通。已内置第一人称摄像机。

## 详细介绍
**不只在高空建设城市，也亲自走进它。**

Real Walking 为《城市：天际线 II》增加能够识别行人路径的第一人称城市探索体验。按下 **Alt+F**，从摄像机附近距离最近、经过安全检查的可步行表面进入，沿着道路、步行街、楼梯、天桥、站台与滨水区域行走；也可以乘坐公共交通，体验自己规划的线路。

### 主要功能
- **真实步行路径：** 根据游戏的行人 Net 与 Navigation Area 识别可步行范围，在道路、楼梯、车站和桥梁上行走，并根据路径表面确定视角高度。
- **快捷进入：** Alt+F 根据摄像机与可步行表面的**三维距离**选择安全落点，不需要精准瞄准画面中心。
- **导航步行 / 自由飞行：** 一键切换。自由飞行使用绝对世界高度，经过海岸、山坡和水面时不会自动升降。
- **公共交通：** 在支持的公交车、有轨电车、地铁、客运火车、摆渡船和客轮停稳时按 **E** 上车／上船；乘坐期间跟随车辆；在可确认安全落点的位置下车／下船。行驶中的车辆不能上车，行驶中的公交或电车也不能按 E 下车。
- **线路与站序信息：** 乘车时显示线路、站名和站序，支持较长的英文站名。
- **统一调试显示：** 可以查看行人道路、导航区域、推断宽度与导航雷达。
- **多语言 UI：** Real Walking 界面支持 12 种语言。

### 快捷键
| 快捷键 | 功能 |
| --- | --- |
| **Alt+F** | 进入／退出第一人称 |
| **WASD**、鼠标 | 移动、调整视角 |
| **Shift** | 步行加速 |
| **E** | 车辆停稳后上车；符合安全条件时下车 |
| **Ctrl+Shift+J** | 导航步行 ↔ 自由飞行；乘车时脱离跟随并飞行 |
| **R / F** | 自由飞行时上升／下降 |
| **Ctrl+Shift+V** | 开启／关闭全部导航调试显示 |
| **Esc** | 退出第一人称 |

### 安装与兼容性
**这是 Standalone 独立版，已内置经修改的 First Person Camera Continued 摄像机。** 不需要另外订阅 FPC；请勿与独立的 FPC Continued、旧版 FPC 分支或其他 Real Walking 摄像机版本同时启用。请先关闭冲突的摄像机模组，再重新启动游戏。

已在 **Cities: Skylines II 1.6.x** 测试。个别自定义车站、码头或复杂区域如果缺少有效导航几何，可能无法找到安全上下车落点。本模组不会主动改变原生交通 AI、市民模拟逻辑或城市存档实体。预计存档风险较低；建议备份重要存档。
