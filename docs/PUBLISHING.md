# Publishing

GitHub repository: https://github.com/brianperezjct33/RealWalking-CS2

1. Upload the **complete source tree**, including `FPCSource/`, `UPSTREAM/`, `LICENSE`, scripts and localization.
2. Confirm the source commit corresponds to the Windows-built and game-tested DLL; record the DLL SHA-256 in the GitHub Release.
3. Use the **existing** Paradox Mods listing **165310** and its new-version publishing profile. Do not create a second listing.
4. Copy the descriptions from [English](PARADOX_MODS_EN.md) or [Chinese](PARADOX_MODS_ZH.md), attach the cover, and verify that the standalone package does not depend on a separate FPC installation.
5. Check the listing, then change its visibility from **Unlisted** to **Public** when ready.
