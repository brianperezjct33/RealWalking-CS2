# Source map

| Folder | Role |
| --- | --- |
| `src/Bootstrap/` | Initialization, controls, camera integration, recovery and logging |
| `src/Entry/` | Nearest walkable entry and water checks |
| `src/Navigation/` | Net/Area geometry, path boundaries and walking height |
| `src/Transit/` | Boarding, vehicle following and safe disembarkation |
| `src/Routes/` | Transit line and stop display |
| `src/Debug/` | Navigation overlays |
| `src/Localization/` | Translation lookup |
| `FPCSource/` | Embedded First Person Camera Continued engine |
| `RWLocalization/` | Real Walking UI translations |

See [architecture](ARCHITECTURE.md) for the data flow.
